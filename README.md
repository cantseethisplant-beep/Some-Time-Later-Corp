# Some Time Later Corp

An EVE Online corporation hosting and deployment platform concept, intended to help people and conversational AIs make informed choices before an app is built.

**Status: concept and planning only.** There is no working app, supported deployment, verified software catalogue, or measured hosting cost in this repository. Last reviewed: 28 October 2026.

## The idea

EVE corporations often need several community applications but have limited hosting resources and administrator time. Members may have spare hardware, and a corporation may also have a cloud account. The proposed app would let the corporation choose reviewed software, register voluntarily offered hardware, and assign approved hosting tasks through a shared dashboard.

The CEO and selected managers would administer the platform. Hardware owners would set the resources, availability and workloads they permit. Assignments could include operating periods, movement windows, scheduled or on-demand backups, and a CEO or designated recovery custodian.

This is **Build Idea 2** from the original discussion. **Build Idea 1** was a fixed corporation software installation; it could eventually serve as a pilot rather than defining the product for every corporation.

## What a first version might cover

An app catalogue, hardware registration, CEO and delegated roles, owner-approved resource limits, one controlled hosting target, and scheduled and manual backups with a tested restore. Multiple hosts, service movement, failover and cloud provisioning would follow only after that foundation is demonstrated.

Existing Discord communication functions should not be rebuilt or integrated merely to duplicate what the corporation already uses. The product is about choosing and hosting useful applications.

## Project boundaries

This public repository explains the concept. Private development planning and future implementation belong in a separate repository. Do not submit tokens, credentials, real corporation records, member inventories, or private operational details here.
